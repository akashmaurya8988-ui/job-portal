# JobConnect – Full-Stack Job Portal

A modern, role-based Job Portal built with **Next.js (App Router)**, **Tailwind CSS**, **Node.js**, **Express.js**, and **Firebase (Auth, Firestore, Storage)**.

## User Roles
- **Student / Job Seeker:** Browse/search jobs, upload PDF resume, apply, track application status.
- **Recruiter / Company:** Post & manage jobs, review applicants, download resumes, shortlist/reject.
- **Admin:** Manage users, companies, and approve/remove job postings.

## Architecture
- `frontend/` — Next.js + React + Tailwind CSS
- `backend/` — Node.js + Express.js REST API + Firebase Admin SDK
